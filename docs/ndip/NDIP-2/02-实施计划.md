# NDIP 生命周期与认证源码权威分层实施计划

- 工作包：`NDIP-2`
- 当前状态：`Accepted`
- 实施授权：Gate B PASS
- deployment authority：`false`

## 实施切片

1. 更新 NDIP index，明确 proposal、environment 和 release 三条独立轨道。
2. 扩展 acceptance verifier，支持 NDIP-2 closed schema，并能从 immutable Git commit
   验证历史 Accepted package。
3. 引入 `implementation-receipt.json` 和 closed implementation verifier。
4. 引入 `NDIP_RUNTIME_SOURCE` scoped digest 与 historical certification-tooling digest。
5. 将 runnable artifact source identity 解析为 certified runtime source commit，仅当当前
   scoped digest 精确相同；否则保持旧的 exact-HEAD/fail-closed 身份。
6. 用 NDIP-1 complete certification 生成 Implemented closure，保留
   `productionAuthority=false`。
7. 同步 status、audit 和 runbook，明确不执行新部署或压测。

## 验证

- NDIP-1 历史 Accepted receipt 在原 transition commit 上可重算；
- NDIP-2 current Accepted package 与 receipt 可重算；
- NDIP-1 Implemented package、runtime digest、tooling digest 和 evidence digests 通过；
- 修改非规范 README/执行记录不改变 runtime digest；
- 修改 registered runnable source、构建依赖或 registered path set 必须使 runtime digest 失配；
- complete certification 只读重验 PASS；
- `./gradlew check` 通过。

## 非目标

- 不运行新的 24/24、Gate C、SHADOW 或 canary；
- 不部署新环境；
- 不执行压测、容量测试或 production rollout；
- 不改动 Handoff runtime 语义、wire、Store 或 P1 source lock。
