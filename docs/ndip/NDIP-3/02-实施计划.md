## 提交与验证

单 agent 直接 main，无 worktree/实现分支；按可审查批次验证、scoped commit、fetch/ancestry
检查、push origin main 并核验远端 SHA。保留无关变更，不 force-push。
A 的 focused Java 回归与小规模全扫 oracle 先行，之后完整代码/文档门；D/E7 在锁定的新
runtime 上做真实 Pulsar/Kafka、UNKNOWN/Journal/事务/多 Shard 接管和 N/L 分离测量。
所有不支持或未验证组合禁止激活。组件测量不冒充端到端认证。

每批同步主设计、Registry、受影响 ADR、工作包代码设计和 IMPLEMENTATION-STATUS。
B7 依据本次真实用户授权记录常规设计决定并完成新 package 的治理闭合，不复制旧 receipt。
最终 E7 组合通过后才能执行适用环境的 F；迁移适用性从实际环境/数据清单证明。
无适用存量不免除 converter/replay/conflict/rollback/retirement 实现和测试。
